# Treat usage rules as evidence for Platform Admin judgment

Lesson-completion and video-progress breaches produce rule flags without blocking submission or Platform Admin approval. Automatic usage gates can keep requests out of the review queue entirely, including requests after repurchase with retained progress, whereas the agreed workflow leaves the decision with a Platform Admin. Review must expose the relevant figures, thresholds, and breaches so that discretion is informed.

## Consequences

- A learner who has reached 60% completion may submit a request, including after repurchase; the completion breach is visible during review.
- If usage crosses a threshold while a request is pending, the live flag changes without automatically deciding the request or disabling approval.
- Existing usage-based restrictions on the request form and submission action must be aligned with this rule; changing only the approval button is insufficient.
- This decision concerns lesson and video usage gates. It does not waive authorization, purchase ownership, duplicate-request protection, the refund deadline, or the separate handling of team purchases.

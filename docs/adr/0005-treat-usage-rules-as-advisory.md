# Usage flags inform Platform Admin decisions

Lesson completion and Watched thresholds produce flags without blocking a Refund Request or preventing a Platform Admin from approving it. Automatic usage restrictions could exclude a learner who retained learning history after making another Individual Purchase, so review exposes the figures and thresholds for the Platform Admin's judgment.

## Consequences

- A learner with 60% of lessons completed may raise a Refund Request; review shows the completion flag.
- Usage flags update while a Refund Request is open without deciding it automatically.
- Purchase ownership, duplicate Refund Request protection and the deadline remain mandatory. Seats that have been claimed still prevent a Team Licence Refund under [ADR 0003](0003-team-licence-refunds-are-all-or-nothing.md).

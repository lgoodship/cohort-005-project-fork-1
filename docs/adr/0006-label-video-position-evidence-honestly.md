# Describe video-position evidence as video progress

For this slice, use the existing sum of the furthest recorded video position reached in each course lesson and display it as **Video progress (hours)** with an explanation. Seeking ahead increases this measure and rewatching adds nothing, so presenting it as hours watched would overstate what the evidence establishes. Introducing a new system for measuring actual elapsed viewing time is separate work.

## Consequences

- Course progress measures completed lessons; video progress is a separate measure and must not be presented as the same percentage or as verified viewing duration.
- Rule flags may use this measure, but the Platform Admin needs its limitations to interpret the evidence.
- Retaining watch history preserves the evidence available for review without making that evidence more precise or trustworthy than its collection method supports.
